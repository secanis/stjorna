Installation

STJÓRNA runs as two services — a PocketBase backend and a SolidJS frontend — in front of either Docker Compose or Kubernetes.

Docker Compose

Section titled “Docker Compose”

The repository ships a docker-compose.yml that builds and runs both services locally:

  • The frontend listens on http://localhost:3000.
  • PocketBase is bound to 127.0.0.1:8090 (its admin UI is at http://127.0.0.1:8090/_/).
  • Data lives in the named volume pb_data and survives docker compose down (docker compose down -v deletes it).

Caution

Never publish PocketBase on 0.0.0.0 on an exposed host — superuser login is sensitive.

Helm (Kubernetes)

Section titled “Helm (Kubernetes)”

The chart provisions the PocketBase backend, the SolidJS frontend, an optional self-hosted S3 (Garage) dependency, and a TLS-terminating ingress.

Prerequisites

Section titled “Prerequisites”
  • Kubernetes >= 1.20
  • Helm 3 (tested with Helm 4; works with 3.x)
  • An ingress controller (tested with Traefik)
  • cert-manager (tested with a letsencrypt ClusterIssuer)
  • A storage class for the PocketBase PVC (default: longhorn)

Use a values file for production:

The helm install output prints the kubectl get secret commands to read the generated superuser credentials.

First run

Section titled “First run”

The chart creates the first superuser headlessly on the first pod start (a Secret is mounted as PB_SUPERUSER_EMAIL / PB_SUPERUSER_PASSWORD). Open https://<your-host>/setup and sign in with those credentials to walk through storage, tenant and admin-link steps.

Upgrade

Section titled “Upgrade”

Upgrades are data-safe: the Namespace, the PocketBase PVC and the PB_SECRET Secret carry helm.sh/resource-policy: keep, so helm upgrade and helm uninstall leave them in place.

Uninstall

Section titled “Uninstall”

helm uninstall does not delete the Namespace, the PVC or the PB_SECRET Secret. Reclaim storage manually with kubectl delete namespace / kubectl delete pvc when you are sure.

Tip

The full chart reference — including the optional Garage S3 subchart, custom secrets and networking values — lives on the chart’s Artifact Hub page.
